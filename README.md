# Tuttify

Tuttify is een offline oefen-app voor muzikanten. Deze repository bevat de gepubliceerde webversie (gebouwde
bestanden). De app heeft geen account en geen server: alle gegevens blijven op het toestel van de gebruiker.

- App: https://app.mytuttify.com/
- Privacyverklaring: [privacy.html](privacy.html)
- Hulp en contact: [support.html](support.html)

Onderdelen van derden (zoals het spraakpakket in `speech/`) vallen onder hun eigen licenties: zie de
licentiebestanden daar en *Over Tuttify → Licenties* in de app.
